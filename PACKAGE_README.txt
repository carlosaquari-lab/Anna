ANNA — Interactive Video Activities for AAC
Version 1.0.0

INICIO

Ejecute ANNA.exe. No es necesario instalar Python.

ANNA se abre con un proyecto vacío. Para utilizar el ejemplo incluido, abra:

demo_project\washing_hands.json

DATOS LOCALES

ANNA crea sus datos locales en:

%LOCALAPPDATA%\ANNA\anna_data
%LOCALAPPDATA%\ANNA\results
%LOCALAPPDATA%\ANNA\assets

Estas carpetas no contienen datos al distribuirse y se crean cuando son necesarias.
