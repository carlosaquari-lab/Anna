# ANNA demonstration project

This folder contains the **Washing Hands** demonstration project distributed with ANNA 1.0.0.

The example is intended to demonstrate the main ANNA workflow with two videos, a timed pause, an interactive hotspot, and complementary supports. It does not imply clinical objectives or therapeutic outcomes.

## Project file

- `washing_hands.json`

## Included videos

- `videos/VID_20260906_121554.mp4`
- `videos/VID_20260906_121715.mp4`

The project uses relative references to these videos so that the demonstration can be opened from the distributed ANNA folder.

## Interactive content

The current sample includes a timed pause with a hotspot and three support positions. The configured hotspot displays the text **washing hands**. Support 1 displays **SOAP** and uses the support image referenced by the project.

## Opening the example

Start ANNA and open `demo_project/washing_hands.json`, or use the sample-project option provided by the application.

The `session_examples` folders document the intended organisation for identified and anonymous research sessions; they do not contain invented interaction data.

For the provenance and licensing status of the media resources, see `LICENSES_DEMO.md` and the root `RESOURCE_INVENTORY.md`.
